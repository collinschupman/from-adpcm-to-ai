What to measure

Decode CPU

Profile at worst-case voice count, not one sound in isolation.

Memory vs. streaming

Resident assets want cheap decode. Streams want ratio and seeking.

Loops and seeking

Check that sample-accurate loop points survive encoding.

Bitrate per class

Set per asset class, then listen on target speakers and headphones.

Platform rules

Check each platform's format requirements.

Tools and licensing

Confirm encoder support in the pipeline, and any license terms.

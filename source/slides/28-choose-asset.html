How to choose

28

~2 min. The same advice by kind of sound, which is how you will actually set it up. Voice-over: modern games ship huge numbers of VO files, so size is what matters, and Opus wins, even in software, because it has a mode built for speech. Only one or two lines usually play at once, so the decode cost stays small; on platforms that decode Opus in hardware it is not a cost at all. Gunshots, impacts and other short, granular sounds play constantly and are often stitched from small sets of variations. Audiokinetic recommends Vorbis here: it compresses well and is fast to decode everywhere. Opus would work on current consoles but wastes size for little gain. On low-end mobile, ADPCM is the fallback when you need CPU back. Keep these off hardware decoders, per the earlier slide. Longer SFX: use the platform's hardware codec where there is one; otherwise Vorbis, then ADPCM if the CPU is overloaded. Ambience: loops plus detail sounds, sometimes many at once; hardware codec where available, otherwise Vorbis. Music: Opus is excellent for music, but if the music has many layers playing at once, software Opus gets expensive. A hardware codec works if every layer is hardware-decoded; mixing hardware and software layers is risky for sync, because of the one-frame latency from the hardware slide. Vorbis is the second choice. Note that this disagrees with the decision order later in this section on short sounds, where ADPCM comes first; pick one and make the slides agree before presenting.

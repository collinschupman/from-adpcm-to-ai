How to choose

35

~1.5 min. There is no single best codec; it depends what you are optimizing for: quality, speed, file size or sync with other sounds, and the platform decides what is even available. This slide is that question turned into a lookup. Smallest file at equal quality: Opus, then Vorbis. Best quality for the CPU you spend: Vorbis is the fastest perceptual codec in software for its quality, but if the platform decodes Opus in hardware, Opus wins. Raw speed: PCM, then ADPCM, and any hardware codec beats both when it is used in next-frame mode, from the hardware slide. Audiokinetic's suggested default is Vorbis, or Opus where it is hardware-decoded, at mid quality. Then the step people skip: run a sample of your real sounds through the candidates and listen for artifacts before you commit a whole category. One more point from the guide: mixing hardware and software codecs is a good thing, because the CPU decodes the software sounds while the hardware works in parallel; with no software sources at all, you are limited by the hardware decoder's speed, which is not always fast. This is Wwise-centric advice; on Unreal, Bink Audio is the default and fills much of the same role. Source: https://www.audiokinetic.com/en/community/blog/a-guide-for-choosing-the-right-codec/
